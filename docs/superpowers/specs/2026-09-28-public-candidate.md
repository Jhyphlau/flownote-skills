# FLOWnote 公开候选版设计边界

状态：2026-09-28三个实施阶段及最终独立审查完成，交付本地公开候选；尚未授权公开发布。验证范围与限制见 `../../validation.md`。

## 要交付什么

让新用户不依赖作者的私人知识库、电脑路径或父 workspace，就能按说明安装 FLOWnote 核心技能并走通最小知识工作流。保持原本机版不动。项目为独立 Git 仓库，不继承工作台的运行依赖。

候选范围共19项：flownote，以及 flownote-archive、capture、card、distill、explain、inbox、init、legacy、memory、month、note、paper、project、read、review、think、week、year。后18项均保留 flownote- 前缀。

## 结构

- `skills/<name>/`：筛选后的19项技能及其必要 references/assets/scripts；不是本机安装目录的整目录镜像。
- `scripts/` 与 `scripts/tests/`：必要的三平台会话读取器及合成测试，保留原目录布局与行为，不借公开化重构读取逻辑。
- `examples/`：无真实数据的 Vault 约定、会话指针示例、Agent 入口示例。记忆模板优先复用技能自带文件，不维护第二份模板本体。
- `README.md`：首次安装、初始化、日常入口、外部工具缺失的降级说明。
- `SOURCES.md`：来源与许可证据；许可证不明不代表自有，不擅自给合集套统一 MIT。
- `docs/`：公开安全的范围清单、实施计划及验证限制，不放私人审查材料或日志。

## 必须保留的体验

通过 flownote 入口路由；轻量解释、深入思考、材料阅读保持分工。记录必须有可信时间，任务进展与灵感分开。只读/预览不落盘，保存以用户授权为准；review不代替distill保存对话。记忆维护仍按权威任务优先、STATUS最后的约定。

## 公开化的边界

机器路径放在用户自己的会话指针，不进技能；示例不包含真实来源位置。现有UTC+8自然日语义明确声明，不在首版新增多时区引擎。保留中文Vault目录约定，不做国际化或任意目录映射系统。

实际笔记、会话、STATUS、索引、用户档案、插件配置、密钥、日志、本机Git历史均不进入候选版。外围阅读/画图/OCR技能不打包；只登记确实被调用的外部能力和缺失时行为。不改变本机junction、激活、插件或源文件。

不安装ljg-push/git-ship，不增加同步器、发布状态机、自动升级、Tag/Release或CI流水线。首次公开远端、许可证选择及推送另行获批。

## 验收

先拿出19项逐文件公开范围及依赖去向，再生成候选版；必要引用可解析，31项既有读取器测试保持通过。用合成Vault验证初始化、捕获与任务分流、阅读no-save到显式保存、review/distill取材边界。静态检查、子代理模拟和真实客户端发现分别报告，不以一种代替另一种。

未知许可、缺依赖或行为冲突须给出具体证据和影响，不用“加强严谨性”扩张范围。许可未确认的技能不得进入公开提交；若影响19项齐全，则报告候选不完整并停在对应门槛。
