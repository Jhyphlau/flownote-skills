## 🗂️ 项目文件目录

> Dataview 可用且已启用时使用下方查询；否则创建主页时将本节替换为当前项目文件的普通 Markdown 链接列表。无文件时写“暂无项目文件”，不保留无法渲染的查询。

```dataview
TABLE WITHOUT ID
  file.link as "文件",
  file.ext as "类型",
  file.folder as "目录",
  file.mtime as "最后更新"
FROM ""
WHERE startswith(file.folder, this.file.folder)
  AND file.path != this.file.path
SORT file.path ASC
```

## ⏱️ 最近更新

> Dataview 可用且已启用时使用下方查询；否则用实际文件及可核验修改时间列出最近更新。无法读取修改时间时说明“最近更新未核验”，不编造顺序。

```dataview
TABLE WITHOUT ID
  file.link as "文件",
  file.mtime as "最后更新",
  file.ctime as "创建时间"
FROM ""
WHERE startswith(file.folder, this.file.folder)
  AND file.path != this.file.path
SORT file.mtime DESC
LIMIT 10
```
