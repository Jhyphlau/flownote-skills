# 费曼技巧（执行版）

## 何时使用

- 用户希望检验自己的理解，或主动选择通过解释、举例与重述进行学习。
- 制卡或阅读中，用户选择检验理解后可使用；仅有论述不完整或概念混淆不足以触发。

## 不适用

- 首次了解陌生概念或只想听解释：先直接解释，不要求用户完成首次复述。

- 只需快速摘录，不做深挖。
- 只需一步即可纠正的明确事实错误；直接给出依据和正确表述。
- 用户明确要求“先记录，不展开”。

## 最小流程（4步）

1. 选定一个概念（一次只选一个）。
2. 请用户用非术语语言解释给“外行”；Agent 不代替用户完成首次解释。
3. 找到卡壳点（含糊、跳步、无法举例）。
4. 回到资料补洞，再次简化重述。

## 引导问题（可直接问）

- 你能不用专业词，解释 `X` 是什么吗？
- `X` 为什么重要？给一个生活中的例子。
- 哪一段你最难讲清楚？那里通常就是理解盲区。

## 与笔记工作流结合

- `flownote-read`：阅读后先做一次“外行解释”，再决定是否入卡。
- `flownote-card`：把“简化解释 + 例子 + 边界条件”写入永久笔记。

## 输出模板（3-8行）

```text
模型：费曼技巧
概念：{{concept}}
一句话解释：{{plain_explanation}}
关键例子：{{example}}
仍不清楚点：{{gap_or_none}}
下一步：{{re-read_or_record}}
```

## 退出条件

- 用户已重新表述，能够流畅解释，并给出例子或边界条件。
- 用户说“先记下来”或“先到这里”。
