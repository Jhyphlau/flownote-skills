# 苏格拉底式提问（FLOWnote 执行版）

用于问题定义模糊、观点或假设混杂，以及用户希望先明确判断需求的场景。纯事务执行、快速记录或用户不愿被追问时，沿用原请求。

## 必要追问

1. 从当前输入识别本次讨论最终要支持用户作出的判断或行动。已经明确就直接沿用；只有可能改变核心需求的歧义才追问。
2. 涉及外部材料时，仅识别与用户判断有关的核心结论、支撑事实和假设。区分用户自述、观点与已核验证据；缺失证据记为未知，不用猜测补齐。
3. 每次只问一个问题并等待。只有答案可能改变问题定义、判断方向或验证方式时才继续；定义、假设、证据和后果是可选问题角度，不是必须逐项走完的清单。
4. 判断对象、关键未知项和可观察、收集或核验的信号三项明确时立即停止。未知项无需先得到答案，完成的是问题定义。

## 交付与边界

输出重构后的可检验问题，清楚表达上述三项；保留用户真实约束和未解决的假设。如需继续，只说明适合事实核查、解释分析、最小实验、决策分析或其他方法的理由，不代替后续方法完成核查、实验、建议、决策或执行。

本轮只在对话中交付，不自动保存、晋升笔记或更新状态；由原 owner 承接用户后续明确请求。使用自然语言，不展示模型菜单，不追加固定轮数、记录版或“继续深挖/先记录”问句。用户提前要求停止时，交还已明确内容与剩余未知项，不声称澄清完成。

本页规则以用户的判断需求为锚点，在形成可检验问题后停止。
