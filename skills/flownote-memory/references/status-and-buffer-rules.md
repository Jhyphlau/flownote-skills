# 全局状态与缓冲区规则

## STATUS.md 位置

固定路径：`Meta/.ai-memory/STATUS.md`

该路径位于隐藏目录，必须使用文件系统工具读写。`Meta/ai-memory/` 不是合法别名。

`STATUS.md` 是跨会话索引，不是任务事实源。每日笔记、阅读进度、项目页等任务专属文件优先；仅在真实状态变化时增量更新 STATUS，并在写后复读验证。现有文件可保留旧标题，按语义兼容读取，在后续真实更新中渐进迁移。

## 最小结构

```markdown
# AI 记忆 - 全局状态

> 更新时间：{{YYYY-MM-DD HH:mm}}

## 📋 任务缓冲

### 本周待处理
- [ ] {{任务}} (来自 {{YYYY-MM-DD}})

### 以后再说
- [ ] {{任务}} (来自 {{YYYY-MM-DD}})

## 📖 阅读整理

## 🃏 卡片笔记

## 📁 项目

## 🔄 回顾
```

## 任务缓冲生命周期

| 分区 | 写入方 | 读取方 | 清理方 | 规则 |
|------|--------|--------|--------|------|
| 本周待处理 | `flownote-review`（本周做） | `flownote-note`、`flownote-week` | `flownote-week` | 周回顾时必须清空或重分配 |
| 以后再说 | `flownote-review`（以后再说）、`flownote-week` | `flownote-month` | `flownote-month` | 月回顾时必须清空或重分配 |

## 清理约束

- 任务被用户选入当前计划后，立即从缓冲区移除。
- 周回顾后不允许“本周待处理”残留。
- 月回顾后不允许“以后再说”残留。
- 没有任务时保留标题，不删除区块。

## 状态标记建议

| 标记 | 含义 |
|------|------|
| 待xxx | 需要用户动作 |
| 整理中 N/M | 处理中，带进度 |
| 整理中 第N章/共M章 | 阅读按章节处理中 |
| ✅ 已完成 | 可从待处理区移除 |
