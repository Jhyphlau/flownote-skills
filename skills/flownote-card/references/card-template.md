# 永久笔记输出模板

> AI 在生成永久笔记时，必须严格按照下方"完整模板"部分的格式输出。
> 不得自行发明结构，不得省略区块。

## 格式规范

- Frontmatter 使用标准 YAML 语法
- `tags` 使用 Obsidian 默认属性名（非"标签"），值用 YAML 列表格式
- 内部链接使用 Obsidian wikilink 语法：`[[路径|显示名]]`
- 日期格式：YYYY-MM-DD
- 标题必须是断言式陈述句（完整句子表达一个明确观点）

## 完整模板

```markdown
---
创建时间: {{YYYY-MM-DD}}
类型: 永久笔记
来源: {{实际来源笔记或材料名}}
状态: 已完成
tags:
  - {{主题标签1}}
  - {{主题标签2}}
  - {{主题标签3}}
---

# {{断言式标题：完整陈述句，表达明确观点}}

## 核心观点

{{一段话概括核心思想，让没读过原书的人也能理解。使用用户原话。}}

## 详细说明

### 为什么成立

{{解释这个观点成立的理由和证据。来自用户的思考和原文支撑。}}

### 具体实现

{{具体的做法、步骤或应用方式。如有多条，用编号列表。}}

1. **{{要点1}}**：{{说明}}
2. **{{要点2}}**：{{说明}}
3. **{{要点3}}**：{{说明}}

### 边界与适用条件

{{什么情况下成立，什么情况下不成立。限制条件和例外。}}

## 相关笔记

- [[02-培养层/主题笔记/📍 {{主题名}}|📍 {{主题名}}]] - {{关系类型（支持/反对/补充）}}：{{关系说明}}
- [[{{已有永久笔记标题}}]] - {{关系类型}}：{{关系说明}}

## 相关项目

- [[04-创造层/项目/{{项目路径}}/📍 项目总览|{{项目名}}]] - {{应用说明}}

## 参考来源

- 来源材料：[[{{实际来源路径}}|{{来源显示名}}]]
- 具体位置：{{已有的章节、段落或版本定位}}
```

## 关键注意事项

1. **标题是断言式陈述句**，如"帮助用户拒绝非优先任务是任务管理软件的核心价值"，不能是名词短语如"任务管理"
2. **详细说明**必须包含三个子区块："为什么成立" + "具体实现" + "边界与适用条件"
3. **相关笔记**使用 wikilink 格式 `[[路径|显示名]]`，主题笔记路径为 `02-培养层/主题笔记/📍 xxx`
4. **相关项目**使用 wikilink 格式 `[[04-创造层/项目/路径/📍 项目总览|项目名]]`
   只有输入或已核验材料支持具体关联时才填写；没有关联则写“无”，不因目录中存在项目而列候选或制造待确认事项。
5. **参考来源**用 wikilink 指向实际来源笔记（文献笔记、用户记录或冻结快照），标明可核验位置；仅有外部来源时使用实际链接及已有版本信息。不为满足模板创建中转文献笔记，不编造路径、行号或版本。
   来源为对话内用户直接输入且无对应文件时，按路径 C 写“用户思考记录，{{日期}}”文字标注，不使用 wikilink、不创建来源文件。
6. `tags` 必须用 YAML 列表格式，不要用 `[标签1][标签2]`
7. 内容优先使用用户原话，缺失的标"待用户补充"
