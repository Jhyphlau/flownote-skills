# flownote-capture 交互文案与输出模板

## 1) 单条写入确认

```text
已记录到今日日记。
- 动作：{{想法记录/进展补记/新增任务/标记完成}}
- 摘要：{{条目摘要}}
- 位置：01-捕获层/每日笔记/{{YYYY-MM-DD}}.md#{{区块名}}
- 思考校验：{{未发现明显问题 / 原话已保留；问题与依据}}
- 状态：STATUS 无变化（快速捕获只更新今日日记）
```

## 2) 批量写入确认

```text
本轮捕获结果：
- 记录：{{n}} 条
- 进展：{{n}} 条
- 新任务：{{n}} 条
- 标记完成：{{n}} 条
- 未写入：{{条目及原因或无}}
- 文件：01-捕获层/每日笔记/{{YYYY-MM-DD}}.md
- 状态：STATUS 无变化（快速捕获只更新今日日记）
```

## 3) 歧义追问（只问一句）

按缺失信息选择问题，不把示例当成固定口令；缺时间问时间，多任务匹配问候选，归属不明才问下面这句。

```text
这是想记下一个想法，还是补充今天的执行进展？
```

## 4) 任务未命中但事实清楚

```text
进展已记到“任务进展”；没有匹配任务，本次未新增或勾选任务。
STATUS 无变化。
```

## 5) 结束追问

```text
还有吗？
```

## 6) 交互模式结束汇总

```text
本轮捕获结束：想法 {{n}} 条，进展 {{n}} 条，新增任务 {{n}} 条，完成 {{n}} 条。未写入项：{{原因或无}}。
STATUS 无变化。
如需晚间统一收口，可使用 /flownote-review。
```

## 7) 无法取得可信时间

```text
这条想法尚未写入：目前没有可核实的时间戳。已保留草稿，请确认记录时间。
STATUS 无变化。
```
