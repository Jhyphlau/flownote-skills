# 智能捕获助手

目标：让用户用最少输入完成“随手记”，先捕获，再整理，不丢失任何有效信息。

## 启动即执行

1. 定位今日日记：`01-捕获层/每日笔记/{{YYYY-MM-DD}}.md`。
2. 若不存在，按 `../flownote-note/assets/每日笔记模板.md` 创建六章节日记，以目标日期展开模板变量；写入前先按下方规则确定内容去向及时间，条件不足时不先创建文件。
3. 已有日记兼容旧标题，仅按获准写入需要补目标章节；保留旧正文，不批量迁移。写记录前读取 `references/write-update-rules.md` 的时间戳约束。

## 流程锁定规则（高优先级）

- 用户在捕获过程中提到“阅读/项目/卡片”等词，默认视为捕获内容，不自动跳转到其他技能。
- 仅在两种情况允许切换技能：
  - 用户明确输入其他命令（如 `/flownote-card`）
  - 用户明确要求停止当前捕获
- 流程完成标志：内容已写入正确区块并返回确认结果。

## 重要提醒

- 禁止使用示例数据，所有写入必须基于用户当下输入与真实文件。
- 默认低摩擦：能自动判断就不追问；仅在不确定时追问一句。
- 不美化、不改写用户观点；只允许最小清洗（去语气词、去多余空白）。
- 捕获内容存在明显事实错误、逻辑跳跃或概念混淆时，仍先保留原话写入；随后在确认消息中单独指出问题与依据。未经用户授权，不用纠偏内容覆盖原条目。
- “只要/一定/必然/都/永远”等绝对化因果或全称断言是逻辑校验信号：若用户没有给出机制、条件或证据，确认消息必须指出这是待验证命题，并给出缺失条件。快速捕获不启动费曼追问，除非用户要求展开。
- 当日日记中，个人思考写 `## 记录`，执行事实写 `## 任务进展`，待办写 `## 任务` 或 `## 明日计划`；纯生活事件可写 `## 晚间回顾`，归属有实质歧义时只核实一次。
- 旧标题按语义识别，不重复建立同义区块；映射见 `references/write-update-rules.md`，历史迁移另行授权。

## 捕获主流程

1. 解析输入（单条/批量/空输入进入交互模式）。
2. 按语义区分想法、进展、待办和混合表达；确认权限与必要时间戳。
3. 按下方规则写入对应章节，保留用户原话与必要上下文。
4. 写入后校验（目标条目存在）。
5. 校验内容中的事实错误、逻辑跳跃、概念混淆和绝对化断言。
6. 输出确认（写入结果；必要时单独纠偏；`STATUS 无变化`）。

## 路由优先级（确定性）

按以下顺序判断，避免冲突：

1. 先识别各条语义；多行和混合输入分别判断，不以首个关键词结束整段处理。
2. 明确待办：明日安排写 `## 明日计划`，今日新增写 `## 任务`。
3. 报告行动、结果或完成程度：写 `## 任务进展`；对象明确且满足原任务完成范围时才同步勾选。部分完成保留未完成状态并说明进度。
4. 表达想法、疑问、灵感或感受：写 `## 记录`。“完成不了目标，是不是方向错了”是疑问，不是完成事实。
5. 混合表达分别保存事实与思考，思考保留理解所需的行动背景；不改写观点、不复制整段流水。拆分会改变原意时先核实。用户指定去向与内容用途明显冲突时先核实，不静默改投。

不确定时只问一句：

`这是想记下一个想法，还是补充今天的执行进展？`

## 写入规则

- 记录条目格式：`- {{HH:mm}} {{原话内容}}`；写入前必须取得可信时间并检查格式，缺失则拒绝本次记录写入、只展示草稿或询问时间，不先写后补。具体时间来源及补录规则见 `references/write-update-rules.md`。
- 任务进展保留事实与必要来源；时间已知可写 `- HH:mm 内容`，未知如实说明，不猜造。同一事实已记入进展时，勾选任务不再复制一条流水。
- 新任务格式：`- [ ] {{任务内容}}`
- 明日计划格式：`- [ ] {{任务内容}}`
- 任务完成：在 `## 任务` 中找到最匹配任务，将 `- [ ]` 改为 `- [x]`
- 找不到匹配任务但事实清楚且已授权记录时：保存到 `## 任务进展` 并说明未更新任务，不凭空新增任务；对象本身不明时先询问。
- `flownote-capture` 只负责“写入/更新今日文件”，不做自动跨日分流；仅在用户明确“明天/明日”时写入 `## 明日计划`。

## 交互模式

用户仅输入 `/flownote-capture` 时进入连续捕获：

- 每写入一条后仅追问：`还有吗？`
- 用户输入“完成/结束/没有了”时结束并输出本轮汇总

## 输出标准

- 确认消息必须包含：动作类型、条目摘要、目标位置。
- 存在逻辑校验信号时，确认消息增加“思考校验”：原话已保留、问题类型、依据或缺失条件；不以追问阻塞捕获完成。
- 每次确认都报告：`STATUS 无变化（快速捕获只更新今日日记）`。
- 批量模式必须返回数量汇总（想法 N 条、进展 N 条、任务 N 条、完成 N 条），未写入项单独说明。
- 可选提示后续动作，但不打断当前捕获节奏。

## 检查清单

- [ ] 已定位或创建今日日记
- [ ] 已完成意图判断并路由
- [ ] 已写入目标区块
- [ ] 已完成写入后校验
- [ ] 已完成事实与逻辑校验；命中时已单独纠偏
- [ ] 已返回确认结果
